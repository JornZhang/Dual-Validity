# PUMS-Based Simulations for Dual Validity

This repository contains R code for the PUMS-based simulation setting used in the **Dual Validity** paper. The scripts construct a simulation design calibrated to real data, evaluate the Bell–McCaffrey (BM) adjustment and the wild cluster bootstrap, and generate the corresponding plots.

## 1. Download the data

The data come from the **2024 American Community Survey (ACS) 1-Year Public Use Microdata Sample (PUMS)**, provided by the U.S. Census Bureau:

<https://www2.census.gov/programs-surveys/acs/data/pums/2024/1-Year/>

Download both archives:

- `csv_pus.zip` (person-level data)
- `csv_hus.zip` (housing-unit data)

Extract the archives so that the four CSV files have the following layout, relative to the repository root:

```text
data/
├── csv_pus/
│   ├── psam_pusa.csv
│   └── psam_pusb.csv
└── csv_hus/
    ├── psam_husa.csv
    └── psam_husb.csv
```

The raw PUMS data are **not included** in this repository. The scripts use `data/` by default. To use a different directory, set the `PUMS_DATA_DIR` environment variable to the directory containing `csv_pus/` and `csv_hus/`.

## 2. R scripts

### `PUMS1220_explorationZ.R` — Data preparation and calibration

This script reads the ACS PUMS files, processes the data, and constructs the covariate matrix $Z$ used in the simulations.

It also fits mixed-effects models to estimate the standard deviations of the PUMA-, state-, division-, and individual-level components for the residualized covariate and regression error:

- Covariate components: $\sigma_{P,X}$, $\sigma_{S,X}$, $\sigma_{D,X}$, $\sigma_{e,X}$.
- Error components: $\sigma_{P,\epsilon}$, $\sigma_{S,\epsilon}$, $\sigma_{D,\epsilon}$, $\sigma_{e,\epsilon}$.

These estimates can be inspected using:

```r
VarCorr(cov.Xperp)
VarCorr(cov.eps)
```

The script saves the prepared data, fitted models, and related information to:

```text
data/1222_PUMA_setting.Rdata
```

This generated file is approximately **710,000 KB**, so it is not uploaded to GitHub. Users can regenerate it by running `PUMS1220_explorationZ.R`.

### `PUMS1227_Bell-McCaffery.R` — Bell–McCaffrey adjustment

This script loads `1222_PUMA_setting.Rdata`, runs the simulations for the Bell–McCaffrey-adjusted cluster-robust standard errors, computes Satterthwaite degrees of freedom, and includes code to produce the corresponding plots.

It saves the simulation results to:

```text
0103PUMS_change_sigm_XD_Bell_df.Rdata
```

### `PUMS1227_fwildbootstrap_auto.R` — Wild cluster bootstrap

This script loads the same prepared PUMS setting and uses the `fwildclusterboot` R package to carry out wild cluster bootstrap inference. It also includes code to produce the corresponding plots.

The intended results filename is:

```text
0107PUMS_change_sigm_XD_boot_auto.Rdata
```

**Note:** Ensure that the `save()` and `load()` calls in this script use the same results filename.

## 3. Running the code

Run the scripts from the **repository root**. Install the R packages used by the scripts if needed:

```r
install.packages(c(
  "dplyr", "lme4", "clubSandwich", "fwildclusterboot",
  "ggplot2", "ggpubr", "ggh4x"
))
```

First prepare the data:

```bash
Rscript PUMS1220_explorationZ.R
```

Then run either or both simulation scripts:

```bash
Rscript PUMS1227_Bell-McCaffery.R
Rscript PUMS1227_fwildbootstrap_auto.R
```

The two simulation scripts are independent of each other, but **both require** `data/1222_PUMA_setting.Rdata`, generated by the first script. Simulation results are saved to the current working directory. The complete simulations can require substantial time and memory.

## 4. Data and results availability

Only the R source code is provided here. The original ACS PUMS data can be downloaded from the Census Bureau link above, and all intermediate data and simulation results can be regenerated using the scripts in the order described.
