# Union Data: Empirical Analysis and Simulations

This directory contains R code for the union-data empirical analysis and related simulations in the **Dual Validity** paper. The empirical setting is based on the replication data accompanying the following study:

> Farber, H. S., Herbst, D., Kuziemko, I., and Naidu, S. (2021). “Unions and Inequality over the Twentieth Century: New Evidence from Survey Data.” *The Quarterly Journal of Economics*, **136**(3), 1325–1385. [https://doi.org/10.1093/qje/qjab012](https://doi.org/10.1093/qje/qjab012)

## 1. Obtaining the data

The original replication package is documented on [Harvard Dataverse](https://doi.org/10.7910/DVN/QTDUQ0). Because the full replication files are too large to host there, the Dataverse description directs users to an external download:

- **Harvard Dataverse record:** <https://doi.org/10.7910/DVN/QTDUQ0>
- **Full replication package (Harvard SharePoint):** [Harvard Economics Datasets — download folder](https://hu.sharepoint.com/:f:/s/HarvardEconomicsDatasets/Er6QpM5a_wpCmVBH3vVcHCEBPtH1khu6Geyi-LR2IqyF0A?e=EEhEH2) (link listed in the Dataverse description dated 2021-03-31).
- **Alternative archival record:** [openICPSR, study E179441V1](https://doi.org/10.3886/E179441V1), which also hosts a replication package for the published paper.

Only three Stata datasets from the downloaded replication files are needed for this analysis:

```text
data/
└── wrkdata/
    ├── composite_gallup_boot.dta
    ├── cps_for_union_boot.dta
    └── state_year_union_ineq.dta
```

The original analysis used `~/Data/wrkdata/`. For portability, the directory tree above is recommended; **update the input paths in `Data_Setting.R` to match the location of your downloaded files**. The `.dta` files are not redistributed in this repository.

## 2. Scripts and workflow

### Step 1: Prepare the empirical setting

**`Data_Setting.R`** processes the three datasets and extracts the covariate matrix $Z$ and the AR(1) coefficients associated with the covariate and error processes ($X$ and $\epsilon$).

The processed covariates and other quantities estimated from the real data are saved as:

```text
Data_Setting.Rdata
```

Run this preparation step before the subsequent analysis and simulation scripts.

### Step 2: Generate exploratory plots

**`Exploration_Plot.R`** uses `Data_Setting.Rdata` to produce:

- The relationship between the top-10% income share and union density over time.
- Autocorrelation-function (ACF) plots.

### Step 3: Run the simulations on an HPC cluster

The simulation code is organized according to whether the additional common shocks enter the regression error or the residualized covariate.

| Simulation setting | R script | Slurm submission script |
| --- | --- | --- |
| Common shocks added to $\epsilon$ | `shock_on_eps.R` | `shock_on_eps.sbatch` |
| Common shocks added to $\widetilde{X}_{\perp}$ | `shock_on_Xperp.R` | `shock_on_Xperp.sbatch` |

On an HPC system using **Slurm**, submit the corresponding jobs with:

```bash
sbatch shock_on_eps.sbatch
sbatch shock_on_Xperp.sbatch
```

Before submission, adjust the paths, R environment, resource requests, and other cluster-specific settings in the `.sbatch` files. Make sure the simulation scripts can find the prepared data and that their output directories exist.

### Step 4: Generate coverage plots

**`coverage_plot.R`** reads the simulation results and generates the coverage-probability plots.

Run this script **after** the required HPC simulation jobs have finished and their result files are available at the paths expected by the script.

## 3. Reproducibility notes

1. The external replication package and the three input `.dta` files are not included here. Obtain them from the sources above.
2. `Data_Setting.Rdata` is generated by `Data_Setting.R` and is required by `Exploration_Plot.R` and the downstream analysis as specified in the scripts.
3. The `.sbatch` files are written for a Slurm-based HPC environment; their local paths and computing resources may need adjustment on a different cluster.
4. Simulation output filenames and locations are determined by the R and batch scripts. Check these paths before running `coverage_plot.R`.
